# V1.0 核心场景回归清单（Task057）

在发布 / 打 `v1.0.0` tag 前，按下列项手工确认。阻塞项必须修复或写入「已知限制」。

## 工作区与文件

| # | 场景 | 期望 | 结果 |
|---|------|------|------|
| 1 | 未打开工作区 | 文件树提示；搜索工作区提示「请先打开」；Git 提示先打开文件夹 | |
| 2 | 打开普通文件夹 | 文件树出现；路径显示正确 | |
| 3 | 打开含中文路径的文件夹 / 文件 | 读写无损 | |
| 4 | 打开非 UTF-8 / 损坏文件 | 不崩溃；Toast 可读错误（或跳过） | |
| 5 | 打开 .md → 编辑 → Ctrl+S | Toast「已保存」；isDirty 清除 | |
| 6 | 未保存关闭 tab | 确认弹窗；保存/丢弃/取消正确 | |
